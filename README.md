# Halloween memory game

Игра начинается автоматически при первой загрузке и каждой перезагрузке страницы.  
Все 16 карточек перемешаны и лежат рубашкой вверх, счётчик ходов равен 0, найденных пар — 0 из 8.  
Один ход — открытие двух разных доступных карточек, независимо от того, совпали они или нет.  
Если изображения совпали, обе карточки остаются открытыми до конца игры. Счётчик найденных пар увеличивается на 1.  
Если изображения различаются, обе карточки остаются видимыми примерно секунду, затем закрываются.  

Когда найдены все 8 пар, игра завершена. Открывается модальное окно с сообщением о победе, итоговым количеством ходов и кнопками «Новая игра» и «Закрыть».  

В хедере расположены кнопки «Новая игра» и «Таблица лидеров».  
«Новая игра» начинает игру заново: карточки перемешиваются и закрываются, счётчики обнуляются. «Таблица лидеров» открывает сохранённые результаты в модальном окне.

Игра находится по ссылке: [memory-game](https://bittersweet-disaster.github.io/memory-game/)  
Играть на масштабе страницы 67%.
